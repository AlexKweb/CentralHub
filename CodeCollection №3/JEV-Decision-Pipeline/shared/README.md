# shared/

Общий контракт для `react/` и `go/`. Меняет его только оркестратор; воркеры только читают.

| Файл | Что это |
|---|---|
| `cases.json` | 12 кейсов: цвет, вопрос, ответ, уверенность, путь по карточкам |
| `cards.json` | каталог карточек пяти колонок сцены |
| `schema/` | JSON Schema (draft 2020-12) для обоих файлов |
| `chief.py` | текст для панели chief.py (ASCII) |
| `SIM.md` | контракт симуляции |
| `tools/simref.py` | эталонная реализация (оракул) |
| `tools/gen_vectors.py` | генератор `test-vectors.json` и проверка ссылочной целостности данных |
| `test-vectors.json` | эталонные входы и выходы для паритета React ↔ Go |
| `fonts/` | JetBrains Mono 400/700/800, лицензия SIL OFL 1.1 (`OFL.txt`) |
